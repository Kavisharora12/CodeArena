# CodeArena

CodeArena is a web application designed for practicing coding problems and improving programming skills.

## Features

- User Login
- User Registration
- Forgot Password
- Reset Password
- Coding Problems
- Video Solutions
- User Profile

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Firebase
- React Icons
